Approvals

An approved server runs as the gateway process, with the gateway environment. Its code can read DATA_DIR, which holds every stored credential, token digest, and password hash.

Pinning binds the top-level package only. The transitive dependencies are not pinned: uvx and npx resolve them at each start, and a new release of a dependency can run under an approved revision. A Python package version can also gain a new wheel file after the approval.
